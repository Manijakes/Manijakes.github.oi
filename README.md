# Data Analyst Portfolio

A responsive one-page portfolio website for Ubon Jacobs.

## Files
- index.html — main website
- style.css — responsive styling
- script.js — mobile navigation and year
- README.md — setup instructions

## Customize before publishing
1. In `index.html`, replace `your.email@example.com` with your real email.
2. Replace the LinkedIn placeholder with your actual LinkedIn profile URL.
3. Add screenshots/images of your Power BI dashboard if available.
4. Add links to your GitHub/SQL projects if available.
5. Update project descriptions with real project results/metrics where you have them.

## Run locally
Open `index.html` in a browser.

## Publish
Upload the folder to a static hosting provider such as GitHub Pages, Netlify, or Vercel.
